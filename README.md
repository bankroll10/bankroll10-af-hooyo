# Af Hooyo

Foundation for a Somali speaking-practice app for children and families. The current app contains only three navigable placeholder screens.

Use Node 24.19.0, then run `npm ci` and `npx expo start --web`.

Run `npm run lint`, `npm run format:check`, `npm run typecheck`, and `npm test` before opening a PR. Product context and project rules are in [docs/PRD.md](docs/PRD.md) and [AGENTS.md](AGENTS.md).
