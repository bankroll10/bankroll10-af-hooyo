# Af Hooyo — Product Requirements Draft

## Product context

Af Hooyo is a Somali language learning app for children of the Somali diaspora. It uses Standard Somali in Latin script. The aim is to help children who understand some Somali become comfortable speaking it.

## Target users

- Somali-American children around ages 5–9 who understand some Somali but cannot speak it confidently.
- Fluent parents who manage the account and support practice at home.

## MVP wedge

The core bet is AI-powered speaking practice with an AI “Ayeeyo” character, plus a parent mode that coaches families to use Somali at home. Luuqad and Somali Kids are primarily vocabulary and flashcard apps; Af Hooyo should focus on speaking and family habits. This repository does not implement those features yet.

## Current foundation

The app contains only a placeholder parent gate, demo child profile picker, and child home. Profiles and gate state exist only in memory. No child data, backend, auth, or AI calls are present.
